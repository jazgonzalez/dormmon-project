# Dormmon Project

This project focuses on network configuration and face recognition integration.

## Project Components
* **app.py**: Core application logic.
* **database.py**: Database management and connection scripts.
* **face.py**: Facial recognition module.
* **Architecture**: System design diagrams included in the root directory.

## Setup
1. Activate environment: `.venv\Scripts\activate`.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run: `python app.py`.
